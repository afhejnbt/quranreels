# Quran Reels API

أداة بسيطة (API) تحوّل أي آية قرآنية إلى فيديو عمودي (9:16) جاهز للنشر —
نص عربي بالرسم العثماني + تلاوة صوتية + خلفية متدرجة أنيقة، كل هذا بطلب HTTP واحد.
مصممة عشان تُستدعى مباشرة من **Make.com** (موديول HTTP) بدون أي تكلفة اشتراك شهري.

---

## 1) كيف تشتغل الأداة

```
GET /generate?surah=2&ayah=255&reciter=alafasy
```

الخطوات داخليًا:
1. تجيب نص الآية (رسم عثماني) من [alquran.cloud](https://alquran.cloud/api) — مجاني بدون مفتاح API.
2. تجيب ملف التلاوة الصوتية (mp3) **كاملًا** من نفس المزوّد (الفيديو دائمًا بمدة تلاوة الآية كاملة، بدون قطع).
3. ترسم طبقة نص عربي شفافة باستخدام Pillow + محرك RAQM (يضبط اتصال الحروف
   والتشكيل القرآني واتجاه الكتابة تلقائيًا وبدقة عالية).
4. **تتكيّف مع طول الآية تلقائيًا:**
   - آية قصيرة/متوسطة → تُعرض ثابتة بخط كبير في منتصف الشاشة.
   - آية طويلة جدًا → تُعرض بخط مريح مع تمرير (Scroll) سلس متزامن مع مدة
     التلاوة الفعلية، بدل تصغير الخط بشكل مبالغ فيه أو قصّ النص. أثناء
     التمرير يبقى النص مقصوصًا بدقة داخل منطقته فلا يتراكب أبدًا مع شريط العنوان.
5. **تختار لوحة ألوان واتجاه تدرج عشوائيًا** من ست لوحات مختلفة في كل استدعاء،
   فما تطلع كل الفيديوهات بنفس الشكل.
6. تدمج الخلفية + طبقة العنوان + طبقة الآية + الصوت الكامل في فيديو واحد عبر `ffmpeg`.
7. ترجع الفيديو (`video/mp4`) مباشرة كنتيجة للطلب.

### نقاط النهاية

| Endpoint | الوصف |
|---|---|
| `GET /health` | فحص أن الخدمة شغالة |
| `GET /reciters` | قائمة القراء المتاحين |
| `GET /generate` | يولّد الفيديو ويرجعه كملف mp4 |

### معاملات `/generate`

| المعامل | إجباري؟ | الوصف |
|---|---|---|
| `surah` | لا | رقم السورة (1-114) |
| `ayah` | لا | رقم الآية داخل السورة |
| `random` | لا | `true` لاختيار آية عشوائية من كامل القرآن |
| `reciter` | لا | `alafasy` (افتراضي) / `sudais` / `husary` / `minshawi` |

أمثلة:
```
/generate?surah=112&ayah=1
/generate?random=true
/generate?surah=2&ayah=255&reciter=sudais
```

## 2) النشر المجاني (GitHub + Render)

### الخطوة أ: ارفع الكود على GitHub

```bash
cd quran-reels-api
git init
git add .
git commit -m "Quran Reels API"
```
أنشئ مستودع جديد فاضي على GitHub (بدون README) بأي اسم، ثم:
```bash
git remote add origin https://github.com/USERNAME/quran-reels-api.git
git branch -M main
git push -u origin main
```

### الخطوة ب: انشر على Render (مجاني)

1. سجّل دخول في [render.com](https://render.com) بحساب GitHub.
2. New → **Web Service** → اختر مستودع `quran-reels-api`.
3. Render يكتشف `render.yaml` و`Dockerfile` تلقائيًا ويضبط كل شي.
4. تأكد إن الخطة (Plan) على **Free**، ثم اضغط **Create Web Service**.
5. أول نشر يأخذ 3-5 دقائق (بناء صورة Docker). بعدها بتحصل رابط عام شبيه:
   ```
   https://quran-reels-api.onrender.com
   ```
6. جرّبه مباشرة بالمتصفح:
   ```
   https://quran-reels-api.onrender.com/generate?surah=112&ayah=1
   ```
   المفروض يبدأ تحميل فيديو mp4.

> **ملاحظة عن الخطة المجانية في Render:** الخدمة "تنام" بعد 15 دقيقة بدون طلبات،
> وأول طلب بعد النوم يأخذ 30-50 ثانية إضافية (Cold Start). هذا طبيعي وما يأثر
> على الأتمتة — بس متوقع إن أول تشغيل بالأتمتة يكون أبطأ من البقية.

## 3) الربط مع Make.com

### السيناريو المقترح

```
[Scheduler: يوميًا 9 صباحًا]
        ↓
[HTTP Module → GET https://quran-reels-api.onrender.com/generate?random=true]
        ↓ (الرد يكون ملف mp4 مباشرة)
[Instagram Module → نشر Reel من محتوى الملف الراجع]
```

### إعداد موديول HTTP في Make

1. أضف موديول **HTTP → Make a request**.
2. URL: `https://quran-reels-api.onrender.com/generate?random=true`
   (أو حدد آية معينة عبر `surah` و `ayah` بدل `random`).
3. Method: `GET`
4. **مهم:** فعّل خيار **"Parse response"** واختر تنسيق **"Binary"** (أو ما يعادلها
   بحسب واجهة Make الحالية) عشان يتعامل مع الرد كملف فيديو لا نص.
5. الرد يرجع كملف (Bundle) فيه الفيديو — تقدر تمرره مباشرة لموديول انستقرام،
   أو تحفظه أول بـ Google Drive/Dropbox إذا احتجت خطوة مراجعة قبل النشر.

### ملاحظة عن التوقيت (Timeout)

توليد الفيديو يأخذ عادة 5-15 ثانية (حسب طول الآية)، بالإضافة لاحتمال Cold Start
بخطة Render المجانية (30-50 ثانية إضافية أول مرة). موديول HTTP في Make يقدر
ينتظر حتى 40 ثانية افتراضيًا — إذا واجهت Timeout بأول تشغيل بعد فترة توقف،
جرّب تزيد "Timeout" بإعدادات الموديول، أو أضف موديول HTTP بسيط لعمل "تسخين"
(`GET /health`) قبل استدعاء `/generate` بثوانٍ.

## 4) التخصيص

- **الخلفية:** عدّل أو أضف لوحات ألوان في قائمة `PALETTES` بملف `app/render.py`
  (كل لوحة فيها لون علوي وسفلي ولون العنوان، وتُختار عشوائيًا كل مرة).
- **الخطوط:** بدّل ملفات `.ttf` في مجلد `fonts/` بأي خط تفضّله (يفضّل خط يدعم
  التشكيل القرآني إذا كان للنص الرئيسي).
- **قائمة القراء:** أضف قارئ جديد بتعديل `RECITERS` في `app/quran.py`
  (تأكد إن معرّف القارئ صحيح من [قائمة الإصدارات الصوتية](https://api.alquran.cloud/v1/edition/format/audio)).

## 5) مصادر البيانات (مجانية بالكامل)

- **التلاوة الصوتية:** نفس المزوّد عبر [Al Quran CDN](https://alquran.cloud/cdn).
